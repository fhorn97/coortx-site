# Coortx Website

A self-contained, cinematic marketing site for Coortx.

## Run locally

Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Files

- `index.html` — content and structure
- `styles.css` — responsive design system and animation
- `app.js` — particle universe, Thinking River, interactions and scroll reveal
- `assets/favicon.svg` — site icon

## Customize

Change the beta email in `index.html` by replacing `hello@coortx.ai`.

No external libraries or build step are required.
